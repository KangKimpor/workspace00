# Pages and databases — phase one

Projects remains the home for existing task project presets and now also contains general pages and databases. Creation offers Page and Database beside all existing project presets. Pages support starter content, reusable saved page templates, nesting, search, parent breadcrumbs, favorites, recent pages, duplication, and archive/restore independently of Trash.

General databases are explicitly marked `__workspaceDatabase` and their rows stay out of Today task lists. Creation supplies a title property, optional schema, a saved view, and row defaults. Existing table, list, board, calendar, and gallery views share property definitions while storing their own filters, sort, grouping, visibility, and selected tab. Database items remain editable rich text pages.

Access remains private to the signed-in account (or this browser in local mode). Phase one does not claim public links, invitations, a workspace member directory, formulas, or reliable rollup calculations. Person fields hold an account/email value. New rollup creation is unavailable; imported rollup values are shown honestly as unavailable for calculation. Files properties retain the existing metadata-only limitation; attach actual files in page content.

The web interface inherits the existing spacing, typography, and theme tokens. Phone and tablet creation and settings use the existing accessible sheets, and the editor keeps its touch formatting controls. Native desktop apps remain paused.
